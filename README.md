# Newman Projection Simulator | סימולטור היטלי ניומן

An interactive Hebrew-language Newman projection learning tool for Organic Chemistry 20456.

## Files

- `index.html` — complete standalone simulator (HTML, CSS, and JavaScript are embedded; no build step or external packages are required).
- `.nojekyll` — tells GitHub Pages to serve files without Jekyll processing.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub, such as `newman-simulator`.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository's root (not into an additional folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, and click **Save**.
6. After GitHub finishes deployment, your site will typically be available at:

   `https://YOUR-USERNAME.github.io/newman-simulator/`

   Replace `YOUR-USERNAME` and the repository name with your actual details. You can find the confirmed URL in **Settings → Pages**.

## Local use

Double-click `index.html` to open it in a modern browser. All assets are embedded, so you do not need a server for local practice.

## Notes

This is a teaching simulation using schematic molecular representations and approximate relative conformational energies. It is not a quantum-chemical energy calculator. The controls and answer keys should be reviewed with the instructor before deployment to students.
