# Newman projection simulator – Organic Chemistry 20456

A standalone Hebrew-language interactive learning activity.

## Modes
- 1 – Explore the Newman projection and conformational energy.
- 2 – Predict energy minima/maxima.
- 3 – Practice (conformations and viewing-direction challenges in one tab).

The construction mode has been removed from the visible activity menu. Questions appear above the visualizations in mode 3.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the root directory.
3. Open Settings → Pages → Build and deployment → Deploy from a branch.
4. Select `main` and `/(root)`; save.
5. Visit `https://YOUR_USERNAME.github.io/REPOSITORY_NAME/`.

No external JavaScript libraries or server-side dependencies are required.
